# 04 AI 使用与个人贡献

本项目使用 Codex 辅助梳理题目、设计接口与测试、生成初版代码和文档。`deepseek-flash` 是运行时 Agent 的决策模型；两者角色不同。

候选人确定了题目、3 小时优先级、Python CLI、DeepSeek 模型、结构化动作、合成资料及证据约束，并提供私有 API Key 用于本地真实模型评测。Codex 完成代码编写、文档初稿和本轮自动验证。截止本次提交，候选人亲自修改的代码与亲自执行的测试尚未记录；不能将 Codex 的工作写成候选人的手动实现。候选人复核或修改后，应在后续提交中补充实际文件、命令与结果。

已完成的机器验证：8 个离线测试通过；真实模型六类用例与资料替换实验已经运行，详细结果见 [评估报告](03-evaluation.md)。复测发现初版 DeepSeek 接入的格式失败，并由 Codex 修改模型参数后重新运行；失败和修复均记录在评估报告。没有把 Mock 输出当作真实模型效果。

实际用时：Codex 首次实现及本次复测、修复合计约 30 分钟（2026-10-28）；候选人后续复核时间尚未记录。尚未完成的生产级能力和限制见 [复盘](05-retrospective.md) 与 [评估](03-evaluation.md)。
