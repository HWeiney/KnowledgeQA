# 04 AI 使用与个人贡献

本项目使用 Codex 辅助梳理题目、设计接口与测试、生成初版代码和文档。`deepseek-flash` 是运行时 Agent 的决策模型；两者角色不同。

候选人确定了题目、3 小时优先级、Python CLI、DeepSeek 模型、结构化动作、合成资料及证据约束，并提供私有 API Key 用于本地真实模型评测。Codex 完成代码编写、文档初稿和自动验证。候选人于 2026-10-28 亲自执行单元测试、真实模型样例核验、检索评测，以及明确答案和检索工具失败两个实时用例；[终端截图](03-evaluation.md#现场运行截图)记录了命令与结果。候选人亲自修改的代码尚未记录，不能将 Codex 的实现写成候选人的手动编码。

已完成的机器验证：12 个离线测试通过；真实模型六类用例、资料替换及步数上限实验已经运行，详细结果见 [评估报告](03-evaluation.md)。Codex 还增加逐案 Trace 核验、13 题检索对比、对 JSON 尾随文本的可审计恢复，以及无原文时的制度名称校验；失败和修复均记录在评估报告。没有把 Mock 输出当作真实模型效果。

实际用时：Codex 首次实现、复测及本轮交付完善合计约 40 分钟（2026-10-28）；候选人截图显示的现场验证发生在 16:56–16:58，其他人工复核用时尚未记录。尚未完成的生产级能力和限制见 [复盘](05-retrospective.md) 与 [评估](03-evaluation.md)。
