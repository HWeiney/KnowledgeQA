# 05 复盘

以下为本轮 Codex 根据实施过程写成的复盘初稿，候选人应在最终面试陈述前按个人实际学习与修改经历复核。

最难的问题是让模型在资料冲突时真正读取两份原文，同时防止引用未经读取或不在原文中的片段。最终采用模型选动作、程序执行与校验的分工：模型保留检索/读取/追问的决策权，程序负责证据边界及步数上限。

学习收获：单看最终答案不足以证明 Agent 决策；需要保留动作、工具参数、返回摘要与后续动作，并做资料替换实验。复测发现默认思考模式下 JSON 输出经常混入额外文本；显式关闭后，本轮六类验收和三次追加追问均通过。必须把失败与修复过程写进评估，而不能只展示成功样例。

下一步优先级：先增加模型格式错误的可审计恢复与无结果检索预算，再扩充改写问题集、检索召回指标和冲突适用范围测试；若扩展到真实企业资料，还需要权限控制、版本/生效范围和更可靠的检索系统。
